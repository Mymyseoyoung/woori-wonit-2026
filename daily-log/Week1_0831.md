## 오늘 배운 내용 정리

**사실(Facts): 어떠한 일들이 있었는지**
- HTML: meta 태그(description, viewport), 시맨틱 태그(header/nav/main/section/article/aside/footer), iframe 실습
- CSS: position(relative/absolute), display(block), z-index, flex(container/item, justify-content, order), grid(template-columns, grid-row/column), 미디어 쿼리, hover 실습
- w3schools 이미지 비교 슬라이더 실습(오버레이 대상 이미지 교체, css 파일 분리)
- JavaScript 기초: 인터프리터 vs 컴파일 언어, 변수 선언(var/let/const), 명명규칙(camelCase 등), 자료형(number/string/boolean/null/undefined/bigint/object), 형변환, 연산자(비교/논리/증감), 조건문(if/switch), prompt/alert로 평균점수 계산 실습

**발견(Discovery): 그 속에서 알게된 점은 무엇인지**
- `<div>`는 의미가 없지만 시맨틱 태그는 이름만으로 역할이 드러나서 유지보수와 SEO에 유리함
- position: relative(부모 기준점) + absolute(자식 겹침) 조합으로 오버레이 구조를 만든다는 원리
- flex는 1차원(오뎅꼬치 비유), grid는 2차원 레이아웃이라 용도가 다름
- var/let/const 중 const를 기본으로 쓰고 필요할 때만 let으로 바꾸는 게 협업 시 권장됨
- typeof(null)이 'object'로 나오는 건 자바스크립트의 알려진 버그이며, null 체크는 Boolean 형변환으로 함

**배운점(Lesson Learned): 어떤 점을 배웠는지**
- CSS를 head 안에 두면 검색엔진이 html 구조 파악에 방해받을 수 있어 외부 파일로 분리하는 게 SEO에 유리함
- overlay 이미지 교체 시 CSS의 z-index 값과 클래스 위치를 함께 바꿔야 원하는 요소가 위로 오게 동작함
- 형변환(Number())을 먼저 해줘야 prompt로 받은 문자열 값이 연산에서 의도대로 계산됨

**선언(Declaration): 배우고 알게 된 점을 바탕으로 앞으로 무엇을 하고 싶은지**
- 포트폴리오 실습 파일에 flex(카드 내부 정렬), grid(전체 카드 배치), 미디어쿼리(모바일 대응)를 함께 적용해 반응형으로 완성해보겠다
- div 남발 대신 시맨틱 태그를 우선 사용해서 코드 가독성과 SEO를 챙기겠다
- JS 변수 선언 시 const를 기본값으로 삼고, 재할당이 필요한 경우에만 let으로 바꾸는 습관을 들이겠다
